# 대표 룩 후보 평가

2026-10-05 · 상태: 미검증 후보 6종, 정식 대표 컬렉션에 추가하지 않음.

이번 후보는 기존 색 LUT와 자체 `film-v2` 질감의 조합이다. 새로운 색 LUT, 제조사·실물 필름의 정밀 복제라고 표시하지 않는다. 색 데이터의 출처·라이선스는 [LUT 기록](lut-provenance.md)을 따른다. 사용자가 제공한 MUTED CHROME / DEEP NEGATIVE는 유지하지만 이번 후보의 기반으로 전용하지 않았다.

색 데이터가 원본 LUT와 같은지는 자동 테스트로 확인했다. 색감 목표에 실제로 부합한다는 뜻은 아니다. 권한이 확인된 실제 평가 사진과 iPhone 실기기 접근이 없어 `accepted` 또는 `rejected` 판정은 아직 없다. AI 샘플 7종은 선택을 돕는 데모이며 품질 인증 자료가 아니다.

## 평가 경로

`?film-quality-preview=1`을 붙인 주소의 필터 목록·색감 비교에서 **대표 룩 · 시험중**을 선택한다. 기본 주소에서는 후보를 추천 목록에 추가하지 않는다. 이미 선택한 후보의 유효 설정은 기본 주소에서도 복원·촬영·재현상할 수 있다.

1. 같은 권한 확인 원본의 무보정 / 기존 LUT / 후보 / 질감 꺼짐 결과를 같은 크기로 비교한다.
2. 피부·흰색·음식 색을 해치거나, 기존 LUT와 차이가 작아 선택 가치가 없는 후보는 이유와 입력 출처를 남기고 제외한다.
3. 작은 화면과 1024px 확대, 실제 저장본을 따로 확인한다. 질감 비교는 FX·뷰티·렌즈·날짜·추가 우연성을 제외하므로 최종 결과 확인을 대신하지 않는다.
4. 통과 전에 기본값을 조정했다면 정의와 수치 테스트를 함께 갱신한다. 공개한 ID/버전은 나중에 덮어쓰지 않는다.

필요한 후속 입력: 이용 권한이 확인된 실제 원본 사진, iPhone 15 Pro Max의 Safari/PWA 촬영·복귀·저장 결과. 개인 사진을 서버로 업로드하거나 평가용으로 자동 수집하지 않는다.
