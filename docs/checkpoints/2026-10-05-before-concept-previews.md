# 콘셉트 프리뷰 개선 전 체크포인트

작성일: 2026-10-05 (Asia/Seoul)

사용자 요청에 따라 현재 `feat/creative-capture`의 기존 수정본을 보존하는 커밋이다. 새 콘셉트 샘플이나 LUT 비교 기능의 구현 완료를 의미하지 않는다.

## 포함 범위

- 전면 카메라의 최소 지원 줌 적용과 백그라운드/BFCache 복귀 시 세션·실제 줌 복원.
- 스튜디오 프레임 미리보기, 즉석사진, 여백색·문구, 네컷 자동/수동 및 간격 조절.
- 필터 적용 전 원본 보관·재현상, 프레임별 필름 패턴 유지와 날짜 처리의 기존 수정.
- 날짜 숫자·간격·빨강/옅은 주황 표현과 빈티지 질감 프리셋/저장 시 화질 열화.
- 해당 구현을 검증하는 테스트, 아키텍처·변경 내역과 기존 디자인 방향 문서.

이 커밋은 작업 트리의 기존 제품 코드 수정과 필요한 신규 파일을 포함한다. 로컬 `.impeccable/review` 스크린샷·임시 HTTPS/카메라 진단 스크립트는 삭제하지 않고 커밋에서 제외했다. 다음 단계의 구현 계획 문서는 별도 커밋으로 관리한다.

## 이번에 실행한 검증

| 명령 | 결과 |
| --- | --- |
| `npm run typecheck` | exit 0 |
| `npm run build` | exit 0; 프로덕션 번들 및 PWA 파일 생성 |
| `npm test -- --reporter=line` | 187 passed (12.2m), exit 0 |
| `git diff --cached --check` | 공백 오류 없음 |

실행 중 제품 코드·테스트를 수정하지 않았다. 테스트는 기존 Playwright 설정의 Chromium 가짜 카메라/SwiftShader와 프로덕션 preview를 사용한다. 실제 iPhone Safari/PWA의 광각과 복귀 동작을 이번에 물리 기기로 검증했다는 의미는 아니다.

## 이후 작업과 경계

- 7종 샘플·동일 원본 LUT 비교·스튜디오 UI 정리는 작성된 구현 계획의 검토 뒤 진행한다.
- 기존 촬영 화면·필터·레시피·보관 데이터의 동작을 보존한다.
- 새 LUT 동봉, 프로덕션 push·배포 및 블로그 업데이트는 이 체크포인트에 포함되지 않는다.
