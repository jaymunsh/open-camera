# 선택형 필름 질감 검증

2026-10-05 · 단계 1A · 전체 회귀 검증과 최종 리뷰 진행 중.

## 구현 범위

- 기존 셰이더 문자열과 기본 필터를 유지하고 `film-v2`를 명시적으로 선택할 때만 새 입자·국소 광원 번짐을 사용한다.
- version 1 설정, manual/profile 구분, 저장 시드, 레시피, 일반·즉석·하프·네컷·다중노출 촬영, 원본 재현상, 불러온 사진 저장에 연결한다.
- 스튜디오의 접힌 ‘필름 질감’, 3종 입자 크기, 주요 조절 2개와 세부 조정 4개, 설정 검사에서 실제 적용값과 비활성 저장값을 구분한다.
- 같은 동결 원본의 질감 비교에는 적용 버튼이 없다. 닫기·취소·오래된 비동기 결과를 정리하고 공유 출력 렌더러를 순차 사용한다.
- 썸네일 캐시 키는 품질 수치·모델·시드·프로필 ID/버전을 포함한다.
- 미검증 후보 6종은 평가 query에만 노출한다. [후보 평가](signature-film-evaluation.md)를 참고한다.

320×240 기준 fixture 3종 × 기존 모델 4종의 GPU 픽셀 SHA-256 12개가 이전 결과와 일치한다. 새 입자는 두 시드, 크기 3종, 512/1024/2048 출력에서 512px로 정규화해 RMS 상대 차이 ≤25%, 상관 ≥.85를 확인했다. 국소 번짐의 반폭 차이는 ≤2px다. 이는 수치 fixture 검증이며 미적 품질·물리적 필름 재현 인증이 아니다.

기존 모델만 사용할 때 추가 셰이더 컴파일은 없고, 새 모델을 반복 렌더할 때 같은 시드의 입자 타일을 다시 올리지 않는다. 컨텍스트 복구를 테스트했다. 새 영상 프레임 업로드와 입자 타일 업로드는 다른 작업이다.

하프프레임의 기존 컷별 색 선택은 유지하고, 첫 컷 이후 새 질감·전체 레시피·효과 해제/취소를 잠근다. 레시피 LUT의 비동기 로딩이 끝난 뒤에도 현재 잠금을 재확인한다. 촬영을 버리고 보관 원본으로 편집하는 기존 명시적 흐름은 복원 가능하다.

## 화면과 제한

320×568, 390×844, 844×390, 1280×800에서 조절판 footer, 비교 닫기, 가로 넘침, 카메라 위치 유지, 포커스 복귀를 검사했다. 첫 비교 화면 캡처에서 발견한 큰 화면의 이미지 잘림을 재현 테스트로 수정하고 같은 네 화면 크기를 재확인했다.

- 실제 iPhone 15 Pro Max Safari/PWA, 복귀 후 카메라 화각, 발열·속도는 미확인이다. Chromium 합성 카메라의 성공을 실기기 성공으로 표현하지 않는다.
- 기존 중립 warp의 128/255 UV 오프셋 때문에 날카로운 경계에서 미러링 원본과 재현상 픽셀이 차이 날 수 있다. 기존 결과를 바꾸지 않기 위해 그대로 두었으며 새 입자 정렬은 균일한 불투명 fixture로 별도 검증했다.
- 손상된 품질 설정은 자동 삭제·초기화하지 않는다. 저장이 막히면 이번 세션에서만 사용하고 경고한다. 잘못된 signature 메타데이터는 원본·기록을 보존하고 재현상을 거부한다.
- 비교는 최대 1024px다. 원본 보관은 기존 opt-in이며 RAW가 아니다. 최근 촬영은 장기 앨범이 아닌 기존 제한 캐시다.
